# 👨🏼‍💻 Vitor Hugo Ramos

## Desenvolvedor de Software | Estudante de Engenharia de Software

Prazer, meu nome é Vitor Hugo Ramos e atualmente atuo como desenvolvedor em um ERP de grande porte, trabalhando na manutenção e evolução do sistema: correção de bugs, ajustes em regras de negócio, criação de telas e investigação de problemas em ambientes produtivos.

Antes de ir para o desenvolvimento, atuei como analista de suporte técnico no mesmo ERP. Essa experiência me deu uma visão muito próxima do cliente e do impacto real de cada problema, algo que hoje uso para entender melhor o que precisa ser corrigido e por quê.

No dia a dia trabalho com uma base de código extensa em C# e VB.NET, com camada de regras de negócio separada da interface, ORM baseado em LinqToDB e fluxo de versionamento com Merge Requests, revisão de código e cherry-pick entre branches de release.

Sou estudante de Engenharia de Software na Univille e, no meu TCC, pesquiso a avaliação empírica de LLMs em tarefas de manutenção de software, com foco em análise de causa raiz e localização de falhas em sistemas legados.

## 🚀 Objetivo

Continuar evoluindo como desenvolvedor back-end, aprofundando conhecimentos em arquitetura de sistemas, banco de dados e qualidade de software, e unindo a experiência prática com sistemas reais à pesquisa sobre o uso de IA na manutenção de software.

## 🛠️ Principais conhecimentos

**Desenvolvimento**
* C# e VB.NET no ecossistema .NET
* Interfaces desktop com WinForms e DevExpress, e telas web com Blazor
* Arquitetura em camadas, separando regras de negócio, acesso a dados e interface
* ORM com LinqToDB, incluindo mapeamento de entidades para PostgreSQL

**Banco de dados**
* PostgreSQL e SQL no geral (consultas, análise de dados, restore de bases)
* Oracle PL/SQL

**Manutenção e qualidade**
* Investigação de bugs e análise de causa raiz em sistemas legados
* Testes automatizados e validação de correções antes da entrega
* Git e GitLab: branches, Merge Requests, revisão de código e cherry-pick entre releases

**Domínio de negócio**
* ERP com foco na área fiscal brasileira: NF-e, MDF-e, ICMS, CFOP e CST

**Pesquisa**
* LLMs aplicados à manutenção de software (análise de causa raiz e localização de falhas)
